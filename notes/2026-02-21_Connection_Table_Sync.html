What Changed

The Closed_cell.py sequence was missing two device blocks (RasteringDevice and BigSkyHub) that exist in the active connection_table.py. Both blocks were copied verbatim to bring the sequence header into full sync. CLAUDE.md was updated with machine identity context and the connection table duplication convention.

Key Decisions

Import pattern, not inline duplication. Initially the RasteringDevice and BigSkyHub blocks were copied verbatim into the sequence. On reflection, we converted Closed_cell.py to use from labscriptlib.Main_Experiment.connection_table import * instead — the same pattern used by jim_DIO_acquire.py. This eliminates the drift risk entirely: the connection table is defined in one place, and all sequences that import it stay in sync automatically.
