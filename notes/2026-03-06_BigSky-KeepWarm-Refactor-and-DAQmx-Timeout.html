BigSky Keep-Warm Refactor + NI DAQmx Timeout Fix

Date: 2026-03-06  •  Commit: pending  •  Context: Move BigSky temperature monitoring from worker to tab; add ZMQ timeouts to DAQmx analog monitor

What Changed

BigSkyHub The "Auto Warmup if Cold" feature was replaced with "Auto Keep Warm" — a tab-side temperature monitor that uses PUB-SUB data already flowing to the GUI thread. This eliminates the ZMQ CHECK_VALUE round-trip that transition_to_manual() previously used to query temperature. The worker now only resets the armed flag; all temperature logic lives in the tab with hysteresis to prevent oscillation.

NI_DAQmx The acquisition worker's ZMQ data_socket (REQ/REP to DataReceiver) could block indefinitely if the receiver was unresponsive after idle. Added RCVTIMEO timeouts (1s for manual/transitions, 5s for post_experiment) and a _send_data() helper that catches zmq.Again and resets the socket. The DAQmx callback thread is wrapped in try/except so a timeout cannot kill it.

Key Decisions

Tab-side vs. worker-side temperature monitoring: The previous design had the worker call CHECK_VALUE via ZMQ during transition_to_manual(). This added latency and coupled temperature logic to a lifecycle method. The tab already receives temperature via PUB-SUB at ~4 Hz, so monitoring there is zero-cost and decoupled from transitions.
Hysteresis thresholds: Trigger warmup at <37°C, reset trigger at ≥39°C. The 2°C gap prevents rapid on/off cycling near the threshold. These match the BigSky's typical cooling rate (~1°C/min idle) and warmup response time (~30s to 39°C).
Stale-event guard on _send_keep_warm_warmup(): Because @define_state(MODE_MANUAL, True) queues the event, a shot could start/finish between when the event is created and when it executes. The guard re-checks _keep_warm_temp[prefix] before acting.
DAQmx timeout strategy: 1s for routine manual-mode sends and mode transitions (local IPC, should be instantaneous). 5s for post_experiment() which sends full-shot data buffers that may be large. The callback thread uses a bare pass in the except block because raising in a DAQmx callback is catastrophic (crashes the NI driver).
