Docs-only session. Started from reading the Matisse C manual + Programmer's Guide for the DSP External Input. Evolved into a parallel-architecture investigation of how to drive the Matisse C-S from BLACS for arbitrary-order setpoint hops without breaking the internal ref-cell lock.

Architectural premise (operator-confirmed). The current setup — WS7's built-in 8-channel PID DAC driving the Matisse Reference Cell external input (item 13) — is structurally equivalent to the Matisse Commander Counterdrift plug-in. Both nest the internal ref-cell lock inside an external servo on the ref-cell piezo. The architecture itself is the fragility source for arbitrary-order hops; swapping who drives the ref cell does not fix it.

Failure Mechanism (Operator-Confirmed)

What breaks the current WS7-direct PID setup on arbitrary-order hops:
  1. BLACS step-changes the WS7 setpoint via SetPIDCourseNum.
  2. WS7 PID aggressively drives the ref-cell DAC voltage.
  3. Internal Matisse ref-cell lock breaks (FASTPIEZO:LOCK? → FALSE): Fast Piezo rails trying to chase the moving flank.
  4. Slow Piezo enters SLOWPIEZO:FREESPEED search mode — sweeps cavity length in one direction.
  5. Cavity moves → Piezo Etalon waveform shakes (downstream effect, not cause).
  6. Re-locks possibly on the wrong mode, or operator gives up.
Operator-confirmed fixes that did NOT work: reducing WS7 PID I gain (too slow), capping cmiDeviationMaxChangePerShot, tuning between close frequencies, continuous ramps (work, but experiment needs arbitrary order).

Patterns Observed

  • Primary sources first, not last. The official LabVIEW Addon zips, the Plug-ins help PDF, and Changelog.md held all the load-bearing answers. I should have read them before drafting recommendations — not after operator pushback.
  • "Looks like it should work" ≠ "documented to work". Counterdrift looks remote-controllable; the API is not in the public VI list. The framing matters: docs should distinguish documented from inferred.
  • Architectural fragility transfers. Three candidates (W, C-static, C-perShot) all nest the internal ref-cell lock inside an external piezo servo. Same failure mode for all three on arbitrary-order hops. Listing them as separate solutions was misleading until §7 made the shared mechanism explicit.
