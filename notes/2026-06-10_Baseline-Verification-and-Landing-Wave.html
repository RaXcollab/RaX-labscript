Friction Points

ObservationCategoryRecommended Action
Survey agents' "verified" claims were each wrong in load-bearing ways: tags exist (they were deliberately deleted), branches local-only (backups existed remotely), C5 additive (v2-coupled), C3 test-only (refactors live workers). Diff-level / wire-level verification during execution caught all four. Agent reliability Treat survey-phase "verified" labels as claims, not facts. Plans must re-verify any claim that gates an irreversible action at execution time — keep the per-step diff gates as a standing pattern.
Restoring deleted tag refs re-created a deliberate fix-by-deletion and broke import labscript_utils for ~50 min (caught only by an unrelated check). Process Before resurrecting any deleted ref/file/config, search for WHY it was absent (git log, notes, memory). Absence can be the fix. Banked: reference_setuptools-scm-tag-import-crash.md; snapshot doc corrected in 56f1c1a.
REPL shell cwd persists across calls — an early cd broke later commands in the same session. Tooling Use absolute paths or git -C <path> in every REPL shell command; never rely on a prior cd.
A JS string-quoting parse error killed an entire batched REPL script, losing all the ops batched with it. Tooling Prefer template-literal / heredoc-safe quoting in batched scripts; keep stateful ops (commits, deletes) in their own small calls so a parse error can't take them down with the batch.
The C6 globals check (ENH_START/ENH_DURATION in BaF_globals.h5) crashed on the tag incident and was never re-run. Process When an incident interrupts a checklist item, explicitly re-queue it — added to the operator-window runbook above as a pre-compile gate.

Recommendations

  • Generalize the tag lesson beyond tags: any "restore missing X" task gets a mandatory "why was X missing?" step first. Applies to refs, config keys, files, and registry entries alike.
  • Survey-agent prompts should require evidence type per claim (wire-verified vs. local vs. inferred), so the executor knows which claims to re-check. The four misses this session were all presented at the same confidence level as the correct claims.
  • CLAUDE.md updates: none needed — the snapshot-pinning convention fix and memory entry were already handled in-session.
