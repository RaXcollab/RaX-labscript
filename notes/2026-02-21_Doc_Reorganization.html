Key Decisions

Centralized notes/ folder vs per-area storage

The old convention ("store notes near the code they describe") led to notes scattered across 4+ directories. Date-prefixed names in a single folder are easier to find and browse. The topic name provides enough context without needing directory proximity.

Unified guide vs two separate docs

The "Using Claude Code" OneNote guide (practical how-to) and Agent System Guide (detailed agent reference) had overlapping sections and diverging information (2 agents vs 6, old colors vs new). Merging eliminates the divergence risk and gives new users one document to read. The unified guide uses tables-first layout: the 6-agent table IS the overview, no redundant prose paragraph before it.

Agent color fix

device-builder was changed from orange to blue. Previously it was identical to amo-expert, making badges indistinguishable. Final palette: blue, orange, red, yellow, green, purple — all distinct.
