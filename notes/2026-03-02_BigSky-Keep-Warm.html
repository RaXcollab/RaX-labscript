BigSky YAG "Keep Warm" Feature + GUI Trigger Mode Fixes

Date: 2026-03-02  •  Commit: pending  •  Context: Add BLACS-managed lamp warmup lifecycle for BigSky YAGs with auto-arm/restore between queued shots

What Changed

Added a "Keep Warm" feature to the BigSky YAG BLACS integration. When enabled, the laser fires its flashlamps on internal trigger (no Q-switch, no shutter) to maintain thermal equilibrium between experiment shots. On transition_to_buffered, the worker automatically arms the laser (external trigger, shutter open, Q-switch armed); on transition_to_manual, it restores warmup state. The _is_armed flag prevents lamp cycling between queued shots.

The external BigSky GUI (BigSkyControllerAmbitious.py) was also fixed: startWarmup() now correctly switches to internal trigger before activating lamps, and startLaser() was rewritten as "Arm External" with proper mode sequencing. Temperature polling is now always-on.

Key Decisions

Option A (internal trigger warmup) over Option B (external trigger + DO line): Option B would require a dedicated digital output line on the NI card to fire lamps externally at ~10 Hz, introducing a cross-device timing dependency and consuming a DO resource. Option A uses the BigSky's built-in internal trigger mode, requiring only serial commands. The tradeoff is a brief lamp interruption during the stop-switch-activate sequence when arming/restoring (~0.3s), but this is acceptable for warmup.
Q-switch mode = External (2) during armed state: The BigSky has three Q-switch modes: Off (0), Internal (1), External (2). During armed state, External mode means the Q-switch fires only when it receives the external trigger from the PrawnBlaster DO line. This is correct for experiment operation.
Remember-only on BLACS restart (no auto-fire): restore_save_data restores the toggle button visual state but does NOT call enter_warmup, because the worker does not exist yet during restore_save_data. The user must re-toggle Keep Warm after restarting BLACS. This is the safe choice: auto-firing lamps on startup without user intent would be dangerous.
_is_armed prevents lamp cycling between queued shots: Without this flag, every transition_to_buffered would call stop-switch-activate on the laser. With queued shots (no transition_to_manual between them), the laser stays armed throughout the queue. Only transition_to_manual (queue end) or abort restores warmup.

Bugs Found & Fixed

Bug: startWarmup() did not switch to internal trigger. The BigSky GUI's warmup function activated lamps without checking/switching the trigger mode. If the laser was previously in external mode (from a shot), lamps would activate in external mode and wait for an external trigger that never comes. Fixed by adding standby-if-needed and setFlashLampInternal() before >a.
Bug: startLaser() did not enforce external modes. The original function sent >a, >r1, >pq without checking modes. If lamps were in internal mode (from warmup), the laser would fire internally at full rate with Q-switch and shutter open. Rewritten with explicit mode enforcement and standby sequencing.
Bug: Temperature polling stopped on stopLaser/warmup completion. tempPollTimer.stop() was called in stopLaser(), pollTemperature() (when warm), and toggleKeepWarm(False). This caused loss of temperature monitoring any time the laser was stopped. Fixed: timer starts once on serial connect and never stops.
Bug: _last_sent_values staleness in transition_to_buffered. Values sent during the buffered programming loop were not tracked in _last_sent_values, so subsequent program_manual calls would re-send them. Fixed by updating tracking after each send.

How to Use

  1. Ensure BigSky GUI is running and connected (verify with /check-guis)
  2. In the BigSky BLACS tab, click Keep Warm: OFF for the desired laser. Button turns amber, lamps begin firing on internal trigger.
  3. Queue experiment shots normally. The worker auto-arms (external trigger) on first transition_to_buffered and skips re-arm for subsequent queued shots.
  4. After the queue completes (transition_to_manual), the worker restores warmup (internal trigger, lamps on, shutter closed).
  5. Click Keep Warm: ON to toggle off. Laser goes to standby.
  6. After BLACS restart: Keep Warm toggle is visually restored but lamps are NOT auto-fired. Re-toggle to resume warming.
