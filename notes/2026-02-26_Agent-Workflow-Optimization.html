What Changed

Surveyed Claude Code Opus 4.6 best practices from official documentation and community forums, filtered for high-synergy improvements to the labscript-suite setup, then implemented 11 changes across CLAUDE.md, agent prompts, skills, settings, and documentation. The theme is context efficiency: load less upfront, delegate structured tasks to cheaper models, persist knowledge across sessions, and give users quick-access workflows via slash commands.

Key Decisions

Sonnet for session-notes and diagnostics, Opus for everything else. Session-notes does structured note-taking (append to file, no complex reasoning). Diagnostics does log parsing and pattern matching. Both are high-volume, low-reasoning tasks where Sonnet is cost-efficient. The remaining agents (blacs-expert, device-builder, amo-expert, lyse-analysis) require complex reasoning about thread safety, device lifecycle, physics, or API design -- Opus stays.
memory: project scope, not user. Project-scoped memory means knowledge is specific to this labscript-suite workspace and shareable via git (the memory files live in the repo). User-scoped memory would mix knowledge from unrelated projects.
background: true on session-notes. Previously required manual Task(background=true) dispatch. The frontmatter flag makes it automatic -- session-notes always runs in background without blocking the main conversation.
Skills use disable-model-invocation: true. Skills are slash-command workflows (checklists, triage procedures), not autonomous agents. They should only fire when the user explicitly types /skill-name, never when Claude decides to invoke them autonomously.
Push guard uses Python for JSON parsing. The PreToolUse hook needs to parse the tool input JSON to extract the bash command. jq was not installed at the time the hook was written (later installed via winget for the status line), so the hook uses python -c "import json..." which is always available.

Context management

  • /clear between unrelated tasks (BLACS debugging, then sequence editing, then analysis).
  • /rename bigsky-debug to name sessions for later resumption with claude --resume.
  • Watch the status line for context usage %. Above 70%, consider /clear or /compact.

@import docs

CLAUDE.md now uses @docs/analysis-api.md, @docs/ni-scope-conventions.md, @docs/blacs-device-patterns.md to load detailed reference docs on-demand. These are only pulled into context when Claude encounters the @import directives while working in relevant areas.

Future Work

  • sonnet[1m] in agent frontmatter: The [1m] context suffix is valid in /model and --model CLI, but the frontmatter validator only accepts base aliases (sonnet, opus, haiku, inherit). If Anthropic adds support, switch diagnostics and session-notes to sonnet[1m] for the full 1M context window at Sonnet cost.
  • Status line refinement: The ~/.claude/statusline-command.sh script is functional but could show more info (active agent, git branch).
