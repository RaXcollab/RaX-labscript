Patterns Observed

  • Cross-verifying parallel audit agents catches their errors. Reconciling the two background audits caught two independent false positives: a memory-dir false-positive from Windows case-insensitive paths, and context-auditor's agent-rename direction being backwards re: GUI files.
  • Domain agents live in three tiers. Top-level .claude/agents/, plus per-GUI GUIs/*/.claude/agents/ (HF_Locking→pid-persistence, rastering→ablation-tech, BigSkyControl→bigsky-yag-laser-controller). Any agent-reference audit must enumerate all tiers before declaring a reference dead.
  • Mixed-tree staging hygiene held. CLAUDE.md was partial-staged via git apply --cached to commit only this session's 2 hunks (GUI-local note, claude-mem gotcha); the RaXcollab-remote rename hunks were left unstaged for their owner.
