# User apparatus examples

This directory contains example connection tables, sequences, subsequences, and RunManager globals.

Use `example_apparatus/` for upstream labscript examples.

Use `Main_Experiment/` for the RaX reference apparatus.

Copy an example before you adapt it to a new computer.

Keep these values in local apparatus files:

- serial ports
- NI Measurement and Automation Explorer names
- external application hosts
- data storage paths

Do not add credentials, personal paths, logs, or generated state.

See [the installation guide](../../INSTALL.md) for profile configuration.
