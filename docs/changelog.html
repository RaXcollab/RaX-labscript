v4.0 — 2026-02-26

Agent workflow optimization: best practices audit, skills, memory, context management

  • CLAUDE.md split with @imports: Extracted BLACS device patterns, NI_SCOPE conventions, and analysis API into docs/*.md files. CLAUDE.md drops from ~290 to ~210 lines. Detailed docs load on-demand.
  • Compaction preservation rules: Added explicit instructions for what to preserve during auto-compaction (routing table, conda command, suppression list, External GUI Registry).
  • Model selection: session-notes and labscript-diagnostics now run on Sonnet for cost efficiency. All other agents remain on Opus for complex reasoning.
  • session-notes auto-background: Added background: true to frontmatter — no longer requires manual background dispatch.
  • Persistent agent memory: Enabled memory: project on blacs-expert, device-builder, labscript-diagnostics, and amo-expert. Agents accumulate institutional knowledge in .claude/agent-memory/.
  • 4 new skills (slash commands):
    • /new-device — full integration checklist for new external GUIs
    • /debug-blacs — standardized BLACS triage workflow
    • /check-sequence — validate globals and device names before RunManager compilation
    • /check-guis — ping all external GUI ZMQ ports to verify they are running
  • Push guard hook: PreToolUse hook blocks git push to backend repos (blacs/, labscript-devices/, labscript-utils/) unless explicitly confirmed.
  • Notification hook: Windows toast notification when Claude needs user attention.
  • Permission cleanup: Pruned accumulated one-off grants from settings.local.json. Pre-approved common git operations in settings.json.
  • Context management guidance: Added /clear between tasks and /rename for sessions to CLAUDE.md and user guide.
  • User guide rewritten to v4.0 with new sections: Skills, Context Management, Agent Memory, Safety & Permissions.

v3.1 — 2026-02-23

Codebase audit fixes + introspection-driven context hardening

  • NI_SCOPE data pipeline: Worker now writes sample_rate, t0, channels_saved as h5 dataset attrs. New channels_to_save parameter enables selective channel saving with NaN-padding for backward compat.
  • Analysis hardening: _resolve_fs_hz() fallback chain in NI_SCOPE.py (attrs → CT properties → user param → 1 MHz). Deprecated kwarg aliases in filtering.py. Exception logging + shape-drop warnings in Abs_data.py.
  • New orchestration row: "Codebase audit / code review" → domain agents. Never use generic Explore for audits.
  • Routing enforcement rule: check file-to-agent routing table before every agent launch (plan mode Phase 1 and 2).
  • Python env preamble: bold warning that every Python command must be preceded by conda activation.
  • "Do NOT Flag These" expanded: NaN rows in NI_SCOPE datasets, deprecated kwargs in analysis utilities.
  • NI_SCOPE Data Conventions section added to CLAUDE.md — h5 layout, attrs, selective saving, NaN-padding pattern.
  • User guide updated to v3.1

v3.0 — 2026-02-23

Agent orchestration upgrade: domain-aware routing, wrap-up agent, anti-patterns

  • New agent: wrap-up — dedicated end-of-session deliverables pipeline (commits, lab notes, introspection, CLAUDE.md updates). Split from session-notes.
  • session-notes narrowed to background note-taking only (decisions, patterns, bugs). No longer owns wrap-up deliverables.
  • Domain-aware routing table added to CLAUDE.md — files route to the agent that owns that path, preventing false positives from generic agents.
  • "Do NOT Flag These" anti-pattern list — RunManager globals, __pycache__, single-occurrence log errors, variable config params, old notebook inline functions.
  • Three-phase workflow — session-notes (start) → domain agents (work) → wrap-up (end). All planned upfront.
  • Agent count: 6 → 7
  • User guide updated to v3.0
