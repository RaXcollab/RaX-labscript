## Scope rules

The active documentation describes implemented behavior or a supported procedure.

Keep drafts, session handoffs, commissioning logs, and completed migration plans outside the active repository.

Use Git history for removed repository documents. Use the private lab notebook for operator history.

Track unresolved work in the project issue tracker. Do not mix completed work with active requirements.
